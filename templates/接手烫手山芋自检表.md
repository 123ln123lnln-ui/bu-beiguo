# 接手烫手山芋自检表（接之前必填）

> 适用：领导安排你接手一个有历史遗留问题/责任不清/多人扯皮的任务（废弃工程、烂尾项目、前任留下的纠纷）。
> 核心认知：「主动担责」是美德，但在烫手山芋上，闷头硬干 = 主动走进责任模糊区 = 替别人的失职背锅。
> **必死结局 = 三个条件同时成立**：①能力不匹配 ②责任真空 ③天然矛盾。拆掉任意一个就不会必死。

## 五问（全部有书面答案才接）

### 一问：该谁干？（职责闸）
- 这件事在我的岗位职责说明书里吗？
- 超出我的专业/能力吗？（如让我估算造价但我不是造价专业）
- 超出 → 书面抛出：「此事需造价咨询/第三方评估支持，建议……」把球踢回流程

### 二问：谁签字、谁担责？（责任闸）
- 最终成果文件上谁签字？签什么栏（经办/复核/负责人）？
- 出了事第一责任人是谁？
- 答不上来 → 书面问清再动

### 三问：有没有"天然矛盾"？（矛盾闸）
- 任务本身是否自相矛盾？（如"按合同概算办"但资料只能"按实计算"；"要组价"但"资料缺失"）
- 有 → **先停下**，书面要求班子会/领导出明确纪要。不澄清，不硬推。

### 四问：留痕链条完整吗？（留痕闸）
- 任务来源有没有书面依据（纪要/批示/ OA 流转）？
- 前任移交有没有字据？资料齐不齐？
- 口头→书面，当场签，不隔夜。

### 五问：我经手的部分，边界在哪？（证据闸）
- 哪些事我经手、哪些没经手？
- 资料缺失/真实性存疑 → 书面标注「无法核实」，**绝不背书、不替施工方补资料、不做无中生有的认定**。

## 填写模板

```
任务名称：
安排人 / 安排时间 / 有无书面依据：
我的职责边界（我做什么、不做什么）：
能力缺口（需要什么外部支持）：
已识别的矛盾点：
需上会/需书面确认的事项：
接手日期 / 前任移交字据（有/无）：
```

填完这份表还决定接 → 把表的关键内容**发邮件/OA 给安排人确认**：「按以上理解接手，有偏差请指正。」——这封邮件就是你的第一份护身符。
