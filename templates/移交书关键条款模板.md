# 移交书关键条款模板

> 来源：提炼自真实追责事件中的关键移交书——其中一句状态声明，在两年后的追责中成为责任分界点铁证。
> 原则：**签字前，责任在移交人；签字后，责任在接收人。移交书的作用就是把这条线画出来。**

## 必备条款（按此结构写）

### 1. 头部
```
《XX 项目/标段管理移交书》
移交人：    接收人：    监交人（重要事项建议加）：
时间：X 年 X 月 X 日
```

### 2. 现状综述（每个事项一段）
- 进展到什么程度、下一步是什么、风险点在哪
- 对每个单位的评价与合作注意事项（如实写，这是交接不是告状）

### 3. ★ 关键条款：未决事项状态声明（责任分界的灵魂）
对每一个**没办完**的事项，必须写清三要素：
```
【事项】XX 索赔/XX 工程：
  已办到：资料已报 XX 部门审定（或：已完成工程量锁定，待 X 环节）
  下一步：督促 XX 尽快审查，进行计量支付（或：……）
  责任归属：自本移交书签署之日起，后续环节由接收人跟进负责。
```

> 真实追责事件中，正是这类状态声明证明：**移交时该事项已到「报审」阶段，后续环节与移交人无关。**

### 4. 资料交接目录（表格）
| 序号 | 文件/资料名称 | 编号 | 数量 | 是否原件 |
|---|---|---|---|---|
（逐项列清，原件/复印件标注，缺一页都写明）

### 5. 双方确认
```
移交人确认以上内容属实、资料已如数交接；
接收人确认已收到上述资料，已了解各事项现状及后续责任。
移交人签字：      接收人签字：      监交人签字：
```

## 常见错误

- ❌ 只写"相关工作已交接"——没写状态=没画线
- ❌ 口头交接 + 事后补签——补签时对方可能不认/加条件
- ❌ 接收人不签字就先走人——一式两份，当场签，各留一份
- ❌ 涉密/敏感资料移交无监交人——重要事项必须有第三人在场签字
