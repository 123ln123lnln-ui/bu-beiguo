# bu-beiguo（不背锅）

**国企工程人防背锅生存与成长 AI 技能**——面向施工/设计/监理/业主工程管理岗的 00 后与新人。

> 核心不是防御，是建立**主心骨思维框架**：底盘不翻车、节奏不被打断、持续进步、出淤泥不染。

## 为什么需要它

- 济南"12·30"坍塌事故：停工令交实习生送达未送到，实习生被建议追刑责——**最没权力的岗位，恰恰是追责高发位**
- 上海"楼倒倒"：挂靠项目经理没去过工地，判刑 3 年
- 南昌某设计院：员工离职被追退"预发奖金"6.8 万
- 无数人的真实困境：领导口头安排的事，出事时"我没说过"

这个技能把工程类国企的坑，整理成**处境决策树 + 照念级话术 + 真实判例库**，覆盖从入职到离职的全流程。

## 三层框架

| 层 | 目标 | 内容 |
|---|---|---|
| 底盘层 | 不翻车 | 签字三问、留痕铁律、安全追责地图、证书挂靠判例、制度护身符、审计应对 |
| 稳定层 | 不被打断 | 破事隔离 SOP（限额 20% 精力）、情绪法则、内耗止损、复位仪式 |
| 成长层 | 持续进步 | 四货币（证书/作品/口碑/选择权）、项目变作品 SOP、辞职决策清单 |

## 使用方式

把本目录作为 skill 装入支持 Agent Skills 的 AI 助手（如 Kimi Code CLI：放入 `~/.agents/skills/bu-beiguo/`），或直接阅读 markdown 文件学习。

触发词示例：「领导让我签字怎么办」「被审计了」「想辞职」「有人出钱包我的证」。

## 案例与依据
