# 03 安全追责篇：最没权力的人，坐最危险的位子

> 工程类国企最高发、后果最重的坑：**安全事故追责**。它不看你是不是新人、是不是实习生——只看证据链上有没有你的名字。

## 高危岗位地图（刑责高发位）

| 岗位 | 为什么危险 | 真实判例 |
|---|---|---|
| **实习生/新人** | 被安排跑送达、盯现场，处于指令链最后一环 | 济南"12·30"坍塌：停工令交实习生王某某送达施工队，因"个人原因"未送达，次日事故 3 死，实习生被认定负主要责任、取保候审、建议追刑责（央广网 2024-06【已验证】） |
| **施工员** | 明知隐患未阻止作业 = 刑责 | 贴吧总结多份事故判决：施工员即使送达过停工通知仍被判刑，因为明知隐患未阻止作业（【个人自述】，引用遵义 3·15、济南 12·30 报告） |
| **资料员** | 安全资料造假的第一经手人 | 镇江火灾 7 死：资料员伪造签字判实刑（见 01 签字篇） |
| **监理员/专监/总监** | 签字=执业资格作保 | 重庆坍塌 5 死：监理三级全被建议追刑责；丰城电厂 73 死：三名监理负刑责（【已验证】） |
| **安全员** | 口头要求撤离不够 | 毕节滑坡 14 死：安全员已要求撤离但无人执行，15 人被建议追刑责——**口头要求不算数**（中青在线【已验证】） |

## 送达铁律：重要指令，"送达 + 留痕"双确认

济南案的深层教训：停工令 29 日晚制发，交给实习生送达，**没有送达确认机制**。次日上午事故。

如果你经手任何重要指令（停工令、整改通知、风险提示）：
1. **必须当面送达并要求签收**；对方拒签 → 拍照记录 + 文字报告上级"已送达 XX，对方拒签"
2. 无法送达（联系不上/进不了场）→ **立即书面上报**，说明送达失败及原因，留好证据
3. 发工作群 ≠ 送达。重要指令必须到具体人、有签收回执。
4. 永远别当"口头传话的最后一环"——话从你嘴里断的，责任就从你身上起。

## 发现隐患的正确动作（免责路径）

1. **书面报告**：隐患描述 + 位置 + 风险 + 建议措施，发 OA/邮件/工作群（文字）
2. **建议停工**：危大工程隐患，书面建议局部停工
3. **留送达证据**：已读回执、签收、会议记录
4. **跟进记录**：整改期限到了没整改 → 再次书面催告并抄送上一级

做到这四步，你就是"已履职尽责"；事故真发生了，这四步是你的免死金牌。
做不到这四步，"我早就说过"在法庭上 = 没说过。

## 如果你是新人/实习生，被安排干这些要警觉

- "把这份停工令带给施工队" → 要求书面签收流程，或请正式员工陪同
- "这份资料你补一下/签一下" → 拒绝，见 01 签字篇
- "现场你盯着，出了事先顶上" → 书面确认你的职责边界：「我是实习生，我的职责是 XX，请确认」
- **不丢人**：问清职责、要求指导，是新人权利。济南案的实习生如果当时多问一句"送达不了怎么办、要不要签收"，结局可能完全不同。

## 特大事故的追责链条有多长

丰城电厂"11·24"坍塌 73 死（国务院调查组【已验证】）：31 人刑事强制措施、38 人党纪政纪处分、9 人诫勉——**从现场到机关无人幸免**，"诫勉"已是最轻一档。

## 事故已经发生（第一小时与后续）

- **救人永远第一**：先救人报警，再保护现场，如实报告——救人既是道德法律双重要求，也是法定从轻情节
- **不隐瞒不编造**：事故迟报、瞒报是独立罪名，别在事故上再加事故
- **配合调查边界**：如实说明 + 记不清的核实后书面答复 + 涉及刑责立即咨询律师
- **"顶一下"=共犯**：任何人让你替 TA 扛事故责任——刑责没有"顶包"只有"共犯"，拒绝并留痕
- **家属与媒体**：个人不擅自发声，由单位统一口径——私下表态都可能被录音

**一句话：安全事故里，证据链决定责任链。你管不了工程质量，但你管得了自己的名字出不出现在证据链上。**
