# 09 审计应对篇：被审计/被约谈/被诫勉怎么办

> 本篇方法论提炼自一起真实的工程索赔追责事件复盘（当事人匿名）：一位业主方工程师在索赔事件中被审计追责、最终诫勉结案的完整应对过程。

## 第一步：稳住——先搞清楚你在什么位置

被审计/被约谈时的角色三分：
- **知情人/配合调查**：正常提供材料、如实说明，不需要恐慌
- **问题相关人员**：可能承担一定责任 → 启动五步复盘
- **被追责对象**：已立案/拟处理 → 立即整理证据链 + 考虑咨询律师

**第一个动作永远是：把你经手这件事的全部留痕证据整理出来**（纪要、邮件、移交书、签字单），按时间线排好。不要凭记忆应对询问——写下来，核实过再说。

## 第二步：五步复盘法（责任切分）

1. **还原时间线**：什么事、什么时间、谁决策、谁执行、谁监督——全部落纸面
2. **责任切三层**：
   - **该认的**：你职责内的程序瑕疵，爽快认。认小错是保护大节（当事人认了"清点未签字、部分工程量多计"的把关不严）
   - **不该背的**：发生在你调岗/移交后、他人职责内的——拿证据逐条切出去（当事人用移交书"已报主管部门审定、待计量"条款，把支付环节切出去）
   - **制度性的**：制度不完善、集体决策、领导不到位的——指出"这是公司整体管理问题，非个人能左右"（当事人质疑：专责小组无工作痕迹、监审全程参与却事后称不知情）
3. **准备证据清单**：每条论点对应哪份证据、在哪（当事人列了 9 项证据，逐项标注存放位置）
4. **核对处理依据**：给你的处理援引什么制度条款？条款适用对不对？程序合不合规？
5. **定应对策略**：配合说明 / 书面申辩 / 申诉

## 第三步：自辩/情况说明写作要点

该事件自辩书的四个有效论点结构（可直接套用）：
1. **执行者非决策者**：「流程集体决策、概算上级审定，为何个人背锅？」——列明各环节都是"纪要分工+多部门参与+领导审批"
2. **时间切割**：「我于 X 年 X 月调岗并书面移交，后续环节未参与」——移交书是责任分界点
3. **结果方向**：「从对方申报到最终审定，我经手的部分是核减方向，保护了公司利益」——用数字说话
4. **定性质疑**：「费用支付尚未发生、双方未签协议，何来损失？」——打掉扣帽子的前提

**语气**：对事不对人、讲证据讲制度、最后落脚"恳请实事求是核查"——不控诉、不情绪化。

## 第四步：处理落地后怎么办（诫勉结案样本）

当事人的务实出路（诫勉、结案、相关领导已退休）：
1. **别主动翻案**：翻案成本高、成功率低、得罪在位的人
2. **守住底稿**：自辩材料、证据链完整存档——未来述职、复盘、万一旧事重提，直接调取
3. **重建信任**：诫勉定的是"程序把关不严"，不是"损失"、不是"贪"。用后续的规范留痕 + 业绩，把"可靠的人"印象重建起来
4. **诫勉影响期约 6 个月**（取消评优、不得提拔）——影响期内低调出活，别争别抢

## 关键窗口：审计报告征求意见期

审计报告正式出具前有**征求意见环节**——这是你唯一法定的逐条申辩窗口。动作：书面逐条回应 + 每条附证据编号 + 要求附卷归档。错过这个窗口，报告定稿后再喊冤，分量天差地别。

## 红线

- 如实说明，**不隐瞒、不编造**——对抗调查比问题本身严重得多
- 不串供、不销毁证据（销毁证据直接升级成刑事问题）
- 涉及刑事责任（安全事故、经济问题）→ **立即咨询律师**，技能只给流程框架
