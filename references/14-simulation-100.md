# 14 百轮推演库（v2.0 迭代记录）

> 方法：100 轮场景推演，覆盖"应对全流程"（入职→日常→人际→事发→事后→成长→定力），聚合为 7 大维度 100 个子场景，不逐条流水罗列。
> 每子场景：场景 → 推演遗憾点 → 迭代落位（→ 指向具体模块）。
> 核心校准：v2.0 定位是**思维框架**而非防御手册——所以推演终点统一收束到"这事该分到哪一层、投入多少精力"。

---

## 维度一：入职期新人局（轮次 1–15）

1. 新人被安排"帮忙签字" → 脸皮薄签了 → 落位：01 签字三问；**入职前 6 个月任何字先问后签**写入 01 新人提示
2. 入职即被分到烂尾/遗留项目 → 闷头接手，跳进责任模糊区 → 落位：templates 自检表前置为"接手任何历史遗留任务必填"
3. 师傅教"灵活处理"（违规操作） → 学了坏习惯还以为是被器重 → 落位：13 成长篇"有毒 mentor 识别"已收；12 篇：礼貌远离不评判
4. 酒桌被劝酒 → 硬喝伤身体，硬拒得罪人 → 落位：12 人际边界（拒酒话术：酒精过敏/开车/吃药三件套，提前布局不临时硬扛）
5. 被安排写别人名字的方案 → 署名权被占 → 落位：13 署名权段（过程稿留痕+书面确认一次+长期作品策略）
6. 试用期被威胁"不表现好不给转正" → 被迫接违规活 → 落位：试用期正常工作成果留痕（02）；违规要求照样过签字三问（01）
7. 新人被当枪使去催别的部门 → 得罪一圈人 → 落位：用流程不用脸——走 OA/函件催办，不做口头催促（02 载体优先级的应用）
8. 证件原件被收走"统一保管" → 离职被卡 → 落位：01 原则延伸——证件原件不离手，只交复印件（复印件标注用途）
9. 被师兄带去"拜码头"站队 → 早早贴上标签 → 落位：13 不站队策略；12"憨厚是最好的盾牌"
10. 人情压力：随礼/集资/请客 → 小额随俗，大额警觉 → 落位：12 人际边界（百元内随俗；千元级/涉及供应商的拒绝——07 廉政红线）
11. 借调上级机关，两边考核 → 两边不是人 → 落位：借调期间工作成果双头书面汇报（02），考核关系书面确认（05）
12. 领导塞私活（接孩子/写私稿） → 白嫖 → 落位：12 限额处理——偶尔帮是人情，常态化接就是没边界；用"手头有 XX 节点"挡
13. 宿舍/工位被欺负 → 小事不争消耗心气，大事不让 → 落位：12 分层——工位是噪音层，不投入；涉及安全/原则才升级
14. 新人参加验收被塞红包 → 人生第一次廉政考验 → 落位：07 廉政红线 + 当场话术「公司有纪律，收了我俩都得写说明」
15. 入职交"押金/保证金/培训费" → 违法收费 → 落位：05 薪酬篇——劳动合同法第 9 条禁止，拒交+留证据

## 维度二：日常事务流（轮次 16–30）

16. 纪要没写你的异议 → 07 已有；推演强化：会后 24h 内核对是最后窗口，超期更正极难
17. 邮件/微信已读不回算不算确认 → 默认不算 → 落位：02 书面化模板加"无回复视为确认"条款的适用范围（仅限低风险事项）
18. 工作群里领导@你表错态 → 情绪化回复被截图 → 落位：08 言行篇——群里只回事实和流程，立场性表态私下说
19. 口头变更设计/方案 → 干了没依据 → 落位：02——变更必须走变更单，口头变更先书面确认再实施
20. 施工方求"通融验收" → 人情签字 → 落位：01+03——验收标准不打折，签"合格"=为质量背书
21. 监理让你补签上月巡视记录 → 倒签=伪造 → 落位：01 代签/补签一律拒绝（镇江资料员判例）
22. 计量单数字对不上 → "差不多就行"签了 → 落位：01 签字三问第一问——看不懂/对不上的不签，核实再签
23. 同事的锅混进你的周报 → 周报变认罪书 → 落位：02——周报写清分工界面（"我负责 A，B 由 XX 负责"）
24. 出差报销被打回扯皮 → 票据丢失 → 落位：02——票据当日拍照归档（云相册/邮箱）
25. 被要求写"自查无问题"报告但你知道有问题 → 两难 → 落位：07+09——写"已发现 X 项，整改中"；把"无问题"改成"已整改"，既真实又保命
26. 常态化无偿加班 → 怨气积累 → 落位：12 限额+05——考勤与加班记录留痕，调休书面化；时机成熟再维权，不日日抱怨
27. 节假日值班被随意安排 → 落位：排班表/值班记录留痕（02）；值班期间做的事全部记录（03：值班期出事故，记录是你的免责链）
28. 公章/资质章被借用 → 章出去责任出去 → 落位：01 延伸——用章登记，复印件标注用途
29. 档案里被放了你不知道的处分材料 → 影响提拔才知道 → 落位：07——每年依规申请查一次本人档案（国企职工权利）
30. 涉密资料拍照带出 → 保密红线 → 落位：07——保密问题不是纪律是法律，零容忍

## 维度三：人际与情绪局（轮次 31–45）

31. 被孤立/边缘化 → 自我怀疑内耗 → 落位：12 分层——不伤底盘的孤立是清净期，正好攒四货币（13）
32. 绩效被恶意打低 → 落位：05——考核申诉渠道+全年成果留痕清单；12——申诉是动作，怨气不隔夜
33. 小圈子拉你入伙 → 落位：12——友好但有限；13——不站队
34. 同事向你吐槽领导 → 你附和，被传话 → 落位：08——只听不接话不转发，「哈哈，都不容易」结束话题
35. 领导抢功 → 憋屈 → 落位：13——成果留痕（过程稿+邮件）；12——这是节奏层不是底盘层，限额处理后回到主线
36. 被造谣 → 想公开对线 → 落位：06——不公开对线，书面澄清一次到位抄送相关方；08——流量不能当武器
37. 前辈打压"年轻人不懂规矩" → 落位：06——用制度回应（"按 X 制度是这样的"）；12——不内耗
38. 同级竞争使绊子 → 想以牙还牙 → 落位：11——竞争在明处，能力说话；13——你的对手不是 TA，是市场价
39. 亲戚托你违规办事 → 亲情绑架 → 落位：07——「制度不允许，我教您走正规流程」给替代方案
40. 领导家属在公司横 → 落位：12——不得罪不亲近，公事公办；交集处全部留痕（02）
41. 和关系户搭档 → 活你干功 TA 领 → 落位：02——界面划清，各自留痕；11——限额，别投入怨气
42. 情绪上头想拍桌子 → 落位：12——10 分钟法则，离开现场
43. 深夜 emo 怀疑人生 → 落位：12——深夜不决策；写下来明天处理
44. 看到不公想举报 → 冲动举报被反噬 → 落位：07——举报四问（证据充分吗/渠道选对吗/实名匿名评估过吗/最坏结果扛得住吗）；09——你是证人不是侠客
45. 深夜想辞职 → 落位：13 辞职决策清单——五问全过再提；12——23 点后的辞职信存草稿箱

## 维度四：事发应对实战（轮次 46–65）

46. 被围签（一群人等你签） → 压力签字 → 落位：01——「我看 10 分钟再签」，离桌看文件
47. 酒后被要求签字/表态 → 落位：01+12——「喝酒不签字，明天办公室找我」
48. 空白页/空白栏 → 落位：01——空白处划线封口再签
49. 系统账号被要求代操作 → 落位：01 延伸——账号操作=数字签名，账号不外借，操作日志就是证据链
50. 电子签章/CA 托管 → 落位：同上——CA 即签名，托管即授权
51. 审计问询紧张说错话 → 落位：09——"记不清的核实后书面回复"；09 演练 8 已验证
52. 查账期间胡思乱想 → 落位：12——破事 SOP：配合动作做完就翻篇
53. 被要求"统一口径" → 串供红线 → 落位：09——如实说明，不串供（对抗调查升级刑事）
54. 审计报告征求意见期 → 唯一法定申辩窗口 → 落位：09——意见期书面逐条回应+附证据，错过不再来
55. 整改报告怎么写 → 落位：09——认领程序瑕疵+整改措施+时限；不扩大认罪范围
56. 会上被点名甩锅 → 落位：06 底线一——当场拿记录平静拆解，话术已预制
57. 邮件被 cc 甩锅（大范围抄送） → 落位：06——回复邮件只列时间线事实，抄送同范围；不骂人
58. 跨部门甩锅（"工程部定的"） → 落位：02+06——分工界面文件/纪要找出来
59. 供应商把责任推给业主代表个人 → 落位：01——我所有指令走 OA/函件，个人不作口头承诺（02）
60. 上级向下级甩锅（"都是小王经手的"） → 落位：06——经手≠决策，会议纪要分工条款调出来
61. 出了安全事故第一小时 → 落位：03——先救人报警，再保护现场，如实报告；不隐瞒不编造（09 红线）
62. 事故后自保与救人的顺序 → 救人永远第一 → 落位：03——道德法律双重正确；救人行为也是减轻情节
63. 配合事故调查的边界 → 落位：09——如实+核实后答+咨询律师（涉刑责时）
64. 事故后家属情绪/媒体围堵 → 落位：08——个人不擅自发声，由单位统一口径；私下表态都被录音
65. 事故后被要求"顶一下"（替人扛责） → 落位：03+06——刑责没有"顶包"只有"共犯"；拒绝并留痕

## 维度五：事后修复与复盘（轮次 66–75）

66. 诫勉后抬不起头 → 落位：09 第四步——别翻案、守底稿、重建信任；12——24 小时内复位主线
67. 处分影响期（约 6 个月） → 落位：07——影响期内低调出活，不评优不争先
68. 被处分后同事躲着你 → 落位：12——正常反应不解读；用下个项目说话（13）
69. 想申诉/翻案 → 落位：09——翻案胜率评估：有新证据+程序违法才值得；否则翻篇（真实复盘的务实选择）
70. 翻案 vs 翻篇判断 → 落位：09——"成本/胜率/得罪人"三问；默认翻篇
71. 失败复盘仪式 → 落位：11——写下来→归档→翻篇；复盘不反刍（12）
72. 和甩锅者还要共事 → 落位：06——公事公办，不交心不结仇；所有交集留痕
73. 声誉重建 → 落位：13——口碑货币是攒出来的；一年内三个靠谱交付可翻盘
74. 心理撑不住 → 落位：12——EAP/12356 心理援助热线/正规医院；承认需要帮助是强不是弱
75. 怎么跟家人说被处分 → 落位：12——说结论不说卷宗：「程序性的事，已处理」

## 维度六：成长与选择权（轮次 76–90）

76. 不知道考什么证 → 落位：13 四货币表——按岗位选主线证书（一建/造价/监理/职称）
77. 项目做完没沉淀 → 落位：13 作品 SOP——结束后 2 周内写技术总结
78. 论文/专利/工法无从下笔 → 落位：13——从技术总结改写； QC 成果门槛最低
79. 没人脉 → 落位：13——行业会议/标准编制/专家库从"参会+提问"开始
80. 不知道自己值多少 → 落位：13——每年市场价评估（投 10 份简历试水）
81. 躺平诱惑/摸鱼合群压力 → 落位：11 出淤泥不染第 3 层；13 躺平陷阱信号（6 个月零新增）
82. 想做副业 → 落位：13 副业红线——先查单位规定；业务相关收费=雷区
83. 跟错领导（被当枪使/不担当） → 落位：13 三标准—— quietly 换部门不撕破
84. 领导调动后新领导清洗 → 落位：13 不站队的回报——业绩中立者最安全
85. 没时间学习 → 落位：12 不可侵犯时间——每天 1 小时雷打不动
86. 身体垮了（工地腰/酒桌肝） → 落位：12——身体是底盘的一部分；拒酒话术；体检异常项建档跟踪
87. 工资月光/乱加杠杆 → 落位：12——强制储蓄；稳定收入≠无限杠杆（房贷/消费贷总额纪律）
88. 35 岁/年龄焦虑 → 落位：13——技术岗 vs 管理岗路线早选；四货币是焦虑的解药
89. 跳槽时机 → 落位：13 辞职清单五问——沉没成本不是成本
90. 离开时的撕破脸冲动 → 落位：13 体面离开——交接留痕是最好的广告，行业圈子很小

## 维度七：出淤泥不染的定力（轮次 91–100）

91. 全员违规的环境（"大家都这么干"） → 落位：11——你可以不合流；用"制度要求"挡，不评判他人
92. 被拉去陪标/围标 → 落位：07——刑事红线，拒绝+留痕；「这事我真做不了，制度查到咱俩都完」
93. 别人摸鱼你不想同流 → 落位：11——不陪绑也不举报；你的节奏自己定（12）
94. 酒桌劝酒文化 → 落位：12——三件套话术；提前布局（开车来/在吃头孢）
95. 被邀请入股领导/同事的"生意" → 落位：07——利益捆绑=廉政雷区，婉拒+保持距离
96. 发现贪腐线索 → 落位：07+09——自保优先：不接触、不传播；举报四问评估（证据/渠道/实名匿名/后果）
97. 长期不提拔的怨气 → 落位：11——提拔是变量，能力是恒量；怨气是最贵的内耗（12）
98. 同侪都升了你还原地 → 落位：11——比较是毒药，节奏是自己的；市场价评估给客观答案（13）
99. 忘了为什么来这 → 落位：11 初心校准——每年写一次"我为什么在这里+今年增值了什么"
100. 终极校准 → 落位：11——**平台是修炼场不是归宿；出淤泥不染=不同流+不缠住+长出来**
