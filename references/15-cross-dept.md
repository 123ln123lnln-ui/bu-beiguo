# 15 跨部门协调篇：文件代替人情，推动而不是抱怨

> 部门墙的本质不是人心坏，是**责任厌恶 + 利益不一致**。人民日报定性：推诿扯皮的温床是"权责不明晰、不对等"（2025-04【已验证】）；中青报调查：79.3% 的人认为踢皮球源于"不愿担责"，67% 认为源于"权责不清"（【已验证，数据较老】）。
> 反制手段必须对症：**书面定界（治权责不清）+ 留痕压责（治怕担责）**。
> 半月谈另一句定性同样重要："基层协调靠刷脸，后患无穷"——人情协调不可靠，制度才长牙。所以本篇核心打法只有一句：**文件代替人情。**

## 一、公司病图谱（先认出这五种病）

1. **踢皮球闭环**：武汉光谷某产业园办预售许可证，"规划局踢给光电办，光电办踢给财政局，财政局踢给审计局，审计局又踢回规划局"——踢完一圈才发现是政策文件过期（湖北日报/央广网 2020-06【已验证】）。特征：球踢一圈回到原点，每个人都"按规定"。
2. **三不管地带**：贵阳两区交界处噪音投诉互转、破损道路拖一年多（半月谈 2021-12【已验证】）。特征：职责交叉区=责任真空区。
3. **二传手部门**："以会议落实会议、以文件落实文件，决策推给上级，责任推给下级"（半月谈 2018【已验证】）。特征：只负责传话，从不负责落地。
4. **会而不决、决而不行**：会开了一堆，纪要没人写，事没人办。
5. **串联会签**：设计变更要经筹建、设计、造价、施工多部门串联会签，有行业文章称平均周期长达 22 天【存疑=量级参考】，任一环节卡住全线停摆。

## 二、核心打法：文件代替人情（四个工具）

### 工具 1：工作联系单（六要素）

别再用嘴和电话催——发**工作联系单**（或 OA 函件），写清六要素：

> **背景**（为什么要）｜**目标**（要什么）｜**时限**（X 日前）｜**验收标准**（什么算完成）｜**签收人**（对方经办人签字/系统签收）｜**升级路径**（逾期未反馈将上报 XX）

依据：企业通行的《工作联系单制度》就是这么硬的——"接单部门主管必须立即签字接收并指定经办人；发单后超时无确认即逐级上报"（管理制度范文【已验证为通行做法】）。
口诀：**联系单不是请求，是签收。**

### 工具 2：会议纪要确认窗（治会而不决）

会后翻供是常态："我没同意这个日期""这不是我们部门的事"。对策（管理方法复盘【个人自述，但机制可靠】）：
- 会后 **30 分钟内**发出结构化纪要
- 开 **2 小时确认窗**：异议只针对三个字段——**结论 / 负责人 / 截止日期**
- 过期视为确认，纪要归档

**沉默即确认。** 纪要不是记录，是各方默认签字的责任书。

### 工具 3：三函升级阶梯（治拖字诀）

官方机制背书：连云港检察院"三色预警"（纸质发函留痕、黄牌催办、红牌督办抄分管领导和纪检，纳入档案）、四川高院"三函问询"（催办函→督办函→警示函）【均已验证=官方机制】。东莞证券招股书里也有"风险提示函/风险警示函/工作督导函"分级【已验证=法定披露文件】——**分级书面函是正规企业的标准动作，不是小题大做**。

落地阶梯：
1. **第一次：工作联系单**（给面子，只发对方经办）
2. **第二次：催办函**（正式，抄双方部门负责人）
3. **第三次：风险提示函**（写明事实+后果+期限，抄分管领导）——例：「该变更会签已逾期 X 天，每延误 1 天影响 XX 节点，若 X 日前未完成将提请领导协调」

**记住：抄送谁，比说什么更重要。**

### 工具 4：RACI 分工表（治职责不清）

职责不清时，**主动画图**而不是等别人划界：

| 角色 | 含义 | 规则 |
|---|---|---|
| R（干活的） | 执行人，可多人 | 写清各自哪一段 |
| **A（拍板兜底的）** | 对结果负最终责任 | **只能有一个**——没有 A 或两个 A 都是事故源 |
| C（会签的） | 需被征询意见 | 列全，缺谁补谁 |
| I（抄送的） | 需被告知 | 领导在这栏 |

画法：把表发工作群——「我拟了分工表，有异议今天下班前提，没异议按此推进」。**沉默即确认**，这张表从此就是分工证据。

## 三、推动别的部门办事（软方法三招）

文件是骨架，人情是润滑剂。体制内协作经验三招（自媒体经验帖【个人自述】，与机制设计互补）：

1. **让功劳**：成果汇报时点名配合部门——「本次节点能保住，多亏造价部 X 工加急」
2. **绑利益**：把配合写进对方 KPI/评优——会上公开感谢 = 给对方送政绩
3. **立规矩**：协作清单双方签字确认，写清各自后果

顺序：**先礼后兵**——软方法开路，联系单压阵。一上来就发函，路会越走越窄；只讲人情没有文件，事会越来越黄。

## 四、向上升级的正确姿势

- **时机**：三级书面阶梯（联系单→催办函→风险提示函）走完之后。带痕迹升级，领导看到的是"该做的都做了"，不是"这人又来告状"。
- **方式**：带方案不带情绪——给领导**两个选项+各自后果**：「方案 A 是 X，风险是 X；方案 B 是 X，风险是 X。您定。」让领导做选择题，不做判断题。
- **禁忌**：越级告状、会上公开指责对方部门、凡事都找领导（管理咨询观点【个人自述】：靠领导协调是毒药——会形成依赖，且领导烦）。

## 五、被踢皮球时（自保侧）

- **首问负责制反向利用**：你书面找的第一个部门 = 首问责任人，按制度 TA 必须办理、指引或转交（甘肃卫健委版文件明确"首问推诿造成后果的问责"【已验证】）——你书面找了 TA，转办和跟进责任就在 TA。
- **你的部分独立留痕**：别人不动，不是你的记录断更的理由。你催过的每一次，都要有书面痕迹。
- **工期风险书面分摊**：青海海北州通报过"不作为慢作为导致重点工程项目久拖未建"被问责【已验证】——工期拖延本身可被问责。所以延误风险**提前书面提示**：「若 X 日前会签未完成，X 节点将延误，责任界面的说明已附」。别让"拖"字的落款是你。

## 六、工程行业高频场景速用

- **设计变更会签卡壳**：发联系单写明「X 日前无异议视为同意，将按程序报审」。注意：**重大变更必须拿到签字**，"沉默即确认"只适用于一般事项。
- **计量支付卡壳**：计量资料按清单一次给齐+签收；卡在哪一环，书面问哪一环——「我司 X 月 X 日报送的第 X 期计量，目前卡在哪个环节，预计何时完成？」
- **监理不签字/不验收**：书面发验收申请+附资料清单；拖延 → 联系单抄送总监及建设单位项目负责人。

## 七、积极视角（本章的落脚点）

**会推事的人升得快。** 推诿的人消耗的是信用，推动的人攒下的是口碑——哪个部门都能配合你、哪个项目到你手里都能转，这就是管理岗的入场券。

别把协调能力理解成"会来事"。它的正式定义是：**用文件固化共识、用阶梯施加压力、用功劳驱动配合**——这三样都是可以学的技术。

> 一句话：扯皮的人赢了一时轻松，推动的人赢了三五年后的位置。抱怨部门墙是最没用的内耗；写出第一张联系单，墙就开始松动了。
